# 🏥 ClinicDesk - نظام إدارة العيادات الطبية المتكامل

نظام إلكتروني متطور لإدارة العيادات والمراكز الطبية، مبني بالاعتماد على لغة **PHP الخالصة (Pure PHP)** باتباع نمط البرمجة كائنية التوجه **(OOP)** ومعمارية **(MVC)** لفصل المسؤوليات، مع واجهات عصرية متوافقة بالكامل مع **Bootstrap 5**.

---

## 🛡️ الميزات الأمنية والتقنية (Core Features)

* **Front Controller Pattern:** نقطة دخول موحدة للنظام عبر ملف `index.php` لإدارة التوجيه والمسارات بشكل آمن.
* **Database Singleton Class:** اتصال موحد وخفيف بقاعدة البيانات يمنع تكرار الاتصالات ويوفر موارد السيرفر.
* **SQL Injection Protection:** حماية مطلقة لكافة الاستعلامات عبر استخدام الـ Prepared Statements.
* **CSRF & XSS Protection:** جدار حماية مشفر للنماذج لمنع هجمات تزوير الطلبات، وتطهير كامل للمدخلات.
* **Role-Based Authentication:** نظام متطور للتحقق من الصلاحيات يحظر الرتب غير المصرح لها برمجياً (مدير، طبيب، مريض).
* **Double-Booking Prevention:** نظام ذكي يمنع حجز موعد مزدوج لدى نفس الطبيب في نفس التاريخ والوقت داتابيز وبرمجياً.
* **Secure File Uploads:** رفع آمن لصور الأشعة والتحاليل الطبية مع فحص صارم للامتدادات والأحجام وتوليد أسماء مشفرة.

## 🚀 طريقة التثبيت والتشغيل المحلي (Installation)

### 1. المتطلبات البرمجية:
* سيرفر محلي (مثل **XAMPP** أو **WampServer**) يدعم **PHP 7.4** أو أعلى، وخادم **MySQL**.

### 2. إعداد قاعدة البيانات:
1. افتح الـ `phpMyAdmin` وأنشئ قاعدة بيانات جديدة باسم `clinicdesk_db`.
2. قم باستيراد (Import) جداول الـ SQL المتواجدة في خطة بناء المشروع بالترتيب (جداول: `users`, `specializations`, `doctors`, `appointments`, `prescriptions`).

### 3. نقل الملفات والإعدادات:
1. ضع مجلد المشروع `clinicdesk` داخل مسار الـ الويب بالسيرفر (مثال: `C:/xampp/htdocs/program/clinicdesk/`).
2. افتح ملف `config/database.php` وعدل بيانات اتصال السيرفر ببياناتك الخاصة.
3. افتح ملف `config/config.php` وتأكد من مطابقة الرابط `BASE_URL` لمسار جهازك الفعلي:
   ```php
   define('BASE_URL', 'http://localhost/program/clinicdesk/');
   ```

## 🖨️ دورة العمل والتشغيل الفعلي (System Workflow)

1. **المدير:** يتابع لوحة الإحصائيات الفورية، ويقوم بإضافة الأطباء وتحديد أسعار كشفية العيادة وإضافة التخصصات الطبية.
2. **المريض:** يقوم بحجز موعد طبي جديد عبر اختيار الطبيب المناسب وتحديد التاريخ والوقت بدقة.
3. **الطبيب:** يستعرض جدول مواعيده الشخصية فقط، ويقوم بالضغط على "كتابة روشتة" ليملأ التشخيص والأدوية ورفع صور الأشعة المساندة، وتتحول حالة الموعد تلقائياً إلى مكتمل.
4. **الطباعة:** يستطيع الطبيب أو المريض فتح الروشتة المعتمدة والضغط على "طباعة" لتجهيزها كملف PDF نظيف وخالٍ من أزرار الموقع.
